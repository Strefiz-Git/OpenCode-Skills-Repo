# Templates

| Pasta | Para quê |
|---|---|
| `skill/` | Esqueleto de uma skill nova (usado por `scripts/new-skill.py`). |
| `project-kit/` | Kit de gestão de projeto copiado do `Repo-Template`: `AGENTS.md`, `opencode.json`, `ROADMAP`, `TODO`, `PROGRESS`, `DECISIONS`, `REVIEW`, `IDEAS`..., `docs/` e `scripts/`. Ler `project-kit/TEMPLATE_GUIDE.md`. |

Para começar um projeto novo: copia `project-kit/` para a raiz, cria `.opencode/{skills,commands,agents,plugins}` e instala as skills com `scripts/install.py`.
